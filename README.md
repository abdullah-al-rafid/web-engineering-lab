# ⏱️ Time-Saving Habit Booster

A web engineering project that helps users build productive habits through short, focused daily tasks.

The application provides 20-minute micro-habit activities, task management actions, weekly progress tracking, and streak monitoring through a simple browser-based interface.

---

## ✨ Features

- ⏱️ 20-minute daily micro-habit tasks
- ✅ Mark tasks as completed
- ⏭️ Skip tasks
- 🔄 Generate a new task
- 📊 Track weekly completion statistics
- 🔥 Monitor productivity streaks
- 👤 Developer information section
- 📩 Contact interface

---

## 🧰 Technologies

- HTML5
- CSS3
- JavaScript

---

## 🎯 Project Purpose

The project was developed as part of a Web Engineering course to practice building an interactive front-end web application using core web technologies.

The main goal is to encourage users to complete small, manageable productivity activities while providing simple progress feedback.

---

## 📂 Project Structure

- `index.html` — Main application interface
- `login.html` — Login interface
- `members/` — Member-related pages
- `script.js` — Application functionality and interactions
- `style.css` — Styling and layout
- `web.zip` — Archived project files

---

## 🚀 Getting Started

Clone the repository:

`git clone https://github.com/abdullah-al-rafid/web-engineering-lab.git`

Open the project directory and launch `index.html` in a modern web browser.

No backend installation is required for the core front-end interface.
